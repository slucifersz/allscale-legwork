Why only on AllScale

email → USDC

Claim Link

The recipient claims with an email code. Funds sit in escrow until claimed; unclaimed funds return to the operator automatically.

< 90 s

Auto-Payout

The agent funds a claim link with one signed API call. Settled on-chain in under 90 seconds.

0 gas

Gasless by design

EIP-7702 delegation: the operator's wallet pays, nobody buys gas, nobody touches a seed phrase.

revocable

Revocable authority

The agent runs on an operator-granted credential with a spending limit. Pull the authorization in the dashboard and the next payout is refused on-chain policy.
